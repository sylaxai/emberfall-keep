EMBERFALL KEEP is a warm fantasy tower-defense game: build five kinds of towers beside a winding road, upgrade them, and hold the keep through 12 waves — including the Ember Titan. Pure canvas 2D and synthesized WebAudio; no libraries, no network, no assets.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```
